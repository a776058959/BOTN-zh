# BOTN 简体中文汉化 · 译文表仓库

本仓库是《Breeders of the Nephelym》0.766.4 简体中文汉化的**译文表更新源**。

## 里面有什么

| 文件 | 用途 |
|---|---|
| `hx_zh.tsv` | 译文表本体（英文<TAB>中文，`#` 开头是注释，含 `@变量@` 模板）。**工具会从这里拉取最新译文**。 |
| `BOTN汉化工具.exe` | 汉化工具。放到游戏目录双击即可安装/卸载汉化、补翻译、检查更新。 |
| `hx_update.txt` | 更新源配置示例：一行一个下载地址。 |

## 玩家怎么用

1. 把 `BOTN汉化工具.exe` 放进游戏目录（根目录或 `BOTN\Binaries\Win64\` 都行）
2. 双击 → 点【安装汉化】
3. 以后想更新译文：点【检查更新译文表】

## 译文表直链

```
https://raw.githubusercontent.com/<用户名>/<仓库名>/main/hx_zh.tsv
```

工具内置了 GitHub 直连与多个国内加速镜像，直连不通会自动切换。

## 想自己补翻译

工具里有完整流程：玩游戏遇到英文 →【采集未翻译】→【复制翻译请求】→ 粘给网页版 AI →
把回复粘回来 →【从剪贴板填入译文】→ 保存 → 重启游戏。译文表格式很简单，两列用 TAB 分隔。

## 说明

- 本仓库**不包含游戏本体**，也不包含任何游戏资源文件。
- 译文表可自由使用、修改、再分发。
